## Hackathon 2025 Solutions by MatchaSpeed

The repository contains the solutions for both the problem statements of the hackathon which are as follows:

1. Build data-driven models to optimize portfolio pricing by understanding price elasticity and cannibalization—maximize MACO with smarter pricing
2. Analyze the long-term impact of brand investments and executions over time on metrics such as Brand Power, Salience, and Consideration

The folder titled 'pricing' contains the solution to the pricing problem statement (problem statement #1) and the folder titled 'brand_power' contains the solution to the brand-equity problem statement (problem statement #2)
